# Available tools in 0.1.2

This page lists the tools available in the planned 0.1.2 release. Each one runs in the browser or through Local Studio.

## Viewer plugins

Available from **Plugins** in the viewer.

**Element Explorer.** A spreadsheet over every element and property in the model.

**Python Console.** Write IfcOpenShell against the open model.

**Quantity Takeoff.** Volumes, areas and counts rolled up by class and storey.

**Room Book.** Every space with its area, volume and occupancy.

**Storey Navigator.** Walk the building one level at a time.

## Built-in tools

Available directly from the viewer.

**Element Schedules.** Tabular exports with resolved property columns.

**IDS Validation.** Check the model against a buildingSMART specification.

**Issue Tracker.** Keep BCF local or sync it with an OpenCDE project.

**Model Checks.** Structural QA over the whole file.

**Model Edits.** Rename, set properties and delete, with a measured diff.

**Smart Filters.** Rule based visibility that you can stack and undo.

## Local Studio

Available after installing Local Studio.

**Assistant Key Vault.** Keep the provider key off the browser.

**IfcOpenShell Converter.** Exact solids and instant reopens.

**MCP Bridge.** Let Claude and other AI clients drive this viewer.

**Native Python.** Full IfcOpenShell scripting with no runtime download.
